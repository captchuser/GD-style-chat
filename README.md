# GD Live Chat

Geometry Dash styled live chat for Twitch and YouTube streams.

- `index.html` is the page. Open it from a web address (GitHub Pages, localhost), not by double-clicking.
- `css/style.css`, `js/app.js`: styling and code.
- `assets/fonts/`: the three GD bitmap fonts (`.png` + `.fnt`). Swap them to restyle the chat.

## Use
- Twitch: `https://YOURNAME.github.io/REPO/?url=twitch.tv/channel`
- Green screen for OBS: add `&green=1&ui=0` (or `&transparent=1`)
- YouTube needs a free YouTube Data API key: add `&key=YOUR_KEY` or paste it in the settings panel.

## GitHub Pages
Upload everything in this folder to a repo, then Settings > Pages > Deploy from a branch > main / (root).
